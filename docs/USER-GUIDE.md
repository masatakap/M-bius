# Möbius 0.8.3

複数の動画を並べて再生するWindows x64用アプリです。ZIPをすべて展開し、`app/Mobius.exe` を起動してください。EXEだけを移動せず、appフォルダー全体を保管してください。.NETの別途インストールは不要です。

## インストーラー改訂2（2026-10-06）

- インストーラーの言語選択に「简体中文」（中国語・簡体字）を追加しました。日本語・英語・スペイン語・フランス語・ポルトガル語と合わせて6言語から選べます。
- アプリ本体は0.8.3のままです。インストーラーの言語とアプリ本体の言語設定は別です。アプリ本体の表示言語は歯車 → 設定 → 言語で選択してください。

## 0.8.3の変更

- 1本表示／拡大表示のシークバー横に **FrameNumber** 入力欄を追加しました。先頭フレームは **0** です。番号を入力して **Enter** を押すと、その位置へ移動して一時停止します。再開は再生ボタンまたはSpaceです。
- 入力中は操作バーを表示し続け、再生位置の更新で入力内容を上書きしません。Escで入力を取り消します。負数・小数・文字列・範囲外の番号は受け付けず、入力欄に有効範囲を案内します。
- フレーム位置は動画から取得したフレームレートと時間で計算します。固定フレームレート素材向けの機能です。可変フレームレート（VFR）や不正確なフレームレート情報を持つ素材では、厳密な通算フレーム番号と一致しない場合があります。フレームレートが取得できない場合は入力できません。
- 下部の再生バーを上部と同じ28pxの高さにしました（100%表示時）。画面の表示倍率に合わせて調整します。
- 半透明の上下操作バーの不透明度を88%から60%へ変更しました。現在の実装では背景とボタン・文字を含むバー全体に適用します。
- 映像の背面と余白を黒にしました。

## 0.8.2の変更

- 拡張子や先頭情報がMP4でも、実体がMPEG-TSになっている一部の動画を自動で読み込めるようにしました。通常の読み込みに失敗した場合だけ、先頭64KiB以内のパケット構造を調べ、該当する場合に1回だけ形式を指定して再試行します。
- この再試行で読み込んだ動画では、シーク時に少し手前から内部で読み進め、指定位置より先に飛ぶ問題を軽減します。元ファイルの変換や書き換えは行いません。
- 通常のMP4やMOV、Hapなどは従来どおり自動判定します。MPEG-TS以外の形式や、映像データ自体が破損しているファイルを修復する機能ではありません。
- Sony X-OCNの対応状況は変更していません。

## 0.8.1の変更

- 歯車を1回クリックしてメニューを開けるよう、非アクティブなバーで最初のクリックが消費される処理を修正しました。
- 上部バーを40pxから28pxへ、右上の各ボタンを44px幅から32px幅へ縮小しました。アイコンも24pxから16pxへ縮小します。数値は100%表示時で、表示倍率に合わせて調整します。
- 「ファイル」の文字を歯車アイコンに変更し、その左に提供いただいたロゴを表示します。タイトルは常に「Möbius」のみです。「表示」メニューも上部に並びます。
- マウスがアプリ内にあっても、3秒間動かなければ操作バーをフェードで隠します。マウスを動かすと再表示します。クリック・ホイール操作でも待ち時間をリセットします。
- メニュー展開中、シーク・音量のドラッグ中、キーボードでバーを操作中は隠しません。「メニュー・再生バーを常に表示」がオンの場合も隠しません。
- 終了時はウィンドウと操作バーを先に隠し、再生・描画を停止してから動画を解放します。読み込み途中の動画や一覧から外した動画の解放も待ち合わせます。ネイティブ再生エンジンの解放は最大4本ずつ専用スレッドで処理します。

終了後に内部の解放処理が少し続くことがあります。60本の合成動画のテストでは、画面の非表示処理が約4ms、解放完了まで約2.3秒でした。素材・保存先・PC構成によって時間は変わります。

## 0.8.0からの機能：自動で隠れる操作バー

- マウスがアプリ内に入ると、上部メニューと下部操作バーを約180msでフェード表示します。マウスが外へ出ると約280ms待ってからフェードで隠します。
- バーは映像の上に半透明で重なります。表示・非表示で映像の表示領域、タイルの配置、再生位置は変わりません。
- シーク・音量のドラッグ中、メニューを開いている間、キーボードでバーを操作している間は表示を維持します。
- 再生バーは1本表示／拡大表示で表示します。複数動画の一覧では下部のスクロールバーを表示します。
- 「歯車メニュー → 設定 → メニュー・再生バーを常に表示」をオンにすると、自動で隠れなくなります。6言語に対応しています。
- 上部中央のタイトル部分をドラッグするとウィンドウを移動できます。ダブルクリックで最大化／復元、右上のアイコンで最小化・最大化・終了、端や四隅でサイズ変更できます。
- F10／Alt+Fでメニューを表示できます。F6で操作バーへ移動し、Tabでボタンを選べます。Ctrl+O、Ctrl+,、Space、F11、Esc等はバーが隠れていても利用できます。
- 動画が未読み込みの場合は、操作方法が分かるように上部メニューを表示します。

各動画のファイル名・解像度欄とアウトラインは従来の表示設定に従います。映像だけを表示する場合は、設定でこの2項目もオフにしてください。

## 0.7.1から引き続き利用できる機能

動画を右クリックすると次の操作ができます。

- **元のファイルの場所を開く**：エクスプローラーで元動画のフォルダーを開き、そのファイルを選択します。
- **コピー**：元動画をファイルとしてクリップボードにコピーします。コピー先のフォルダーで Ctrl+V を押すと複製できます。切り取りではないため元動画は残ります。Möbiusを終了した後も貼り付けできます。

新しい項目とエラー案内は6言語に対応します。元ファイルが移動・削除された場合は案内を表示します。ユーザー提供のアイコンを引き続き使用しています。

### 既知の未完了事項

Windowsの既定アプリ候補一覧・右クリック候補への表示は引き続き調整中です。以下のインストール説明のうちWindows側の関連付けは意図する動作の説明であり、実画面での完了確認はまだできていません。アプリ内の右クリックメニューで追加した2機能とは別の機能です。
公開配布に向けた依存ライブラリーのソース提供・ライセンス整理も準備中です（THIRD-PARTY.md参照）。

## インストールと既定のアプリ（0.7）

`Mobius-Setup.exe` を実行してください。Windows 10/11 x64用です。現在のユーザー専用として `%LOCALAPPDATA%\Programs\Mobius` にインストールし、スタートメニューへ追加します。管理者権限や.NETの追加インストールは不要です。デスクトップのショートカットは任意です。

- 動画を右クリック → 「プログラムから開く」→ Möbiusで開けます。「Möbiusで開く」項目も追加します。Windows 11では「その他のオプションを確認」内に表示される場合があります。
- 複数選択して開いた動画は、起動済みの同じMöbiusにまとめて追加されます。
- 「歯車メニュー → 設定」の「既定のアプリ」横のアイコンを押すとWindowsの設定が開きます。Möbiusの拡張子一覧で `.mp4`、`.mov` などを選び、Möbiusに設定してください。Windows 10や古いWindows 11では一般の「既定のアプリ」画面になる場合があります。その場合は拡張子またはMöbiusを検索して選択します。
- インストールしただけでは、現在の既定のアプリは変更されません。既定アプリの決定はWindowsの画面で行います。
- 更新はMöbiusを終了して新しいセットアップを実行します。以前の設定は引き継ぎます。
- 削除はWindowsの「設定 → アプリ → インストールされているアプリ（アプリと機能）→ Möbius → アンインストール」から行えます。動画と設定ファイルは残します。
- ZIP版は引き続きそのまま起動できます。Windowsへの登録にはインストーラーを使用してください。インストール後はスタートメニューのMöbiusを使うと、別コピーを同時に起動せずに済みます。

登録対象：mp4 / mov / hap / avi / mkv / webm / m4v / mpg / mpeg / wmv / mxf / ts / mts / m2ts / vob / ogv / flv / 3gp。実際に再生できるかはファイル内のコーデックによります。

## 0.6から引き続き利用できる機能

- 「歯車メニュー → 設定 → 言語」で、日本語・英語・スペイン語・フランス語・ポルトガル語・中国語を選択できます。チェックのアイコンで保存すると反映されます。中国語は簡体字、ポルトガル語は欧州表記です。
- メニュー、設定、案内、ステータス、操作アイコンの説明を切り替えます。Windows標準のファイル選択画面や外部ライブラリーの技術的なエラー詳細はOS・ライブラリー側の言語になります。
- ウィンドウのタイトルは「Möbius」のみにしました。
- Hap用の専用GPU再生経路を追加しました。GPU圧縮テクスチャをCPUで通常画像に展開せず、そのままGPUへ転送します。

## HapのGPU処理

|処理|実装|
|---|---|
|BC1 / BC3の映像展開|GPUのテクスチャ展開機能|
|Hap QのYCoCg色変換|GPUシェーダー|
|Hap Alpha / Hap Q Alphaの透過|GPUのアルファ展開・合成|
|BC4 / BC7 / BC6形式|対応するGPU圧縮テクスチャ形式を使用|
|BC6のHDR値から通常画面への変換|GPUの簡易トーンマッピング。HDR出力ではありません|
|拡大・縮小・補間・90度単位の回転|GPU|
|複数動画の合成・無限スクロール・静止画アニメーション|1つのGPU描画面へ合成|
|映像の転送|圧縮データのまま転送し、GPUテクスチャを再利用|

ファイル読み込み、コンテナ解析、Snappy追加圧縮の解除、再生時刻の管理、音声処理はCPUです。Snappyは分割チャンクの並列処理に対応します。「全処理がGPUのみ」という意味ではありません。画面外の動画と手動操作中の動画は停止し、停止中のHap読み込みスレッドも休止します。自動スクロール中は画面内の動画を再生します。

Hap / Hap Q / Hap Alphaの実ファイル再生、Hap Q Alphaの色と透過を合成したGPU出力、BC7/BC6形式のGPUテクスチャ生成を検証しました。Hap R・Hap HDRの実ファイルやHDR表示品質、AMD/Intel GPUは未検証です。対応圧縮形式はGPU・ドライバーに依存します。実素材の4K/8K多数同時再生の速度は別途ご確認ください。

MP4等は従来のmpv経路を利用し、対応する場合はハードウェアデコードします。Hapの音声はmpvで処理し、再生再開・シーク時の同期と再生中の時刻補正を行います。右クリックの動画情報で使用中の経路を確認できます。

## 基本操作

動画・フォルダーをドロップ、または「歯車メニュー → 動画を追加」で読み込みます。フォルダーは直下の動画が対象です。元ファイルの変更・アップロードは行いません。

|操作|動作|
|---|---|
|動画をクリック|その場所を基準に拡大。再生位置を維持|
|拡大動画の再クリック / Esc|一覧へ戻る。フルスクリーン中のEscは先に解除|
|Ctrl＋ / Ctrl－|映像を大きく / 小さくする|
|左ボタンで横ドラッグ|慣性付き横スクロール|
|ホイール / 左右キー|横移動|
|Ctrl+E|自動スクロール開始 / 停止|
|F11|フルスクリーン切り替え|
|Space|再生 / 一時停止|
|Ctrl+→ / Ctrl+←|1フレーム進む / 戻る|
|Ctrl+O|動画を追加|
|Ctrl+,|設定|

1本表示・拡大表示では、下部に再生・停止・コマ送り・シーク・音量を表示します。バーをクリックするとその位置へ直接移動し、ドラッグでも調整できます。停止は先頭へ戻って一時停止します。アイコンにマウスを重ねると操作名が出ます。スピーカーで音声オン/オフを切り替え、音量を0〜100％で調整できます。

「一覧から外す」「一覧をクリア」は元ファイルを削除しません。

## 設定

- 再生モード：クリックした動画のみ、画面内のすべて、マウスオーバー。
- 映像サイズ：高さ80〜1200px。元の表示比率を維持し、縦に収まるよう調整します。
- 動画間の余白：0〜40px、初期値5px。
- ファイル名・解像度の情報欄、アウトラインの表示切り替え。
- 拡大中の動画だけ音声を再生する設定。
- 自動スクロール速度：10〜600px/秒、初期値80px/秒。
- 表示言語：6言語。

手動の追加・配置変更・スクロール中は静止画で動かし、操作終了から約200ms後に再開します。1本の場合は中央に最大表示します。少数ファイルを大量に複製して画面を埋めることはありません。無限スクロールの境界では同じGPUテクスチャを再利用します。

以前の設定を引き継ぐため、保存先は `%LOCALAPPDATA%/VideoMosaic/settings.json` のままです。

## 検証とビルド

検証範囲は `TEST-RESULTS-0.8.3.md`、依存ライブラリーは `../THIRD-PARTY.md` を参照してください。インストーラーのソースは配布ZIPの `installer/` に収録しています。

Windowsと.NET 9 SDKでビルドします。

```powershell
dotnet publish source/VideoMosaic.csproj -c Release -r win-x64 --self-contained true -p:PublishReadyToRun=true -p:PublishSingleFile=false -p:DebugType=None -o app
dotnet run --project tests/LayoutTests.csproj -c Release
```

ネイティブのHapコンテナ読み取り部は、Visual Studioのx64 Native Toolsコマンドプロンプトから `source/build-native.cmd <FFmpeg SDKフォルダー>` でビルドできます。FFmpeg 8.1 shared SDKのinclude/libを使用し、appにavformat-62.dll、avcodec-62.dll、avutil-60.dll、swresample-6.dllを配置します。libmpv-2.dllも必要です。

`Mobius.exe --self-test <合成動画ファイルのパスを複数指定>` は統合テスト、`Mobius.exe --verify <Hapテスト動画>` は言語・圧縮データ・シーク検証です。結果は実行ファイル横にJSONで保存します。設定ファイルは変更しません。
