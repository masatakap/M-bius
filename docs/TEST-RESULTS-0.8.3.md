# Möbius 0.8.3 検証結果

2026-10-06 / Windows x64 / NVIDIA GeForce RTX 4070 Ti

## 今回の変更と確認

- シークバー横にFrameNumber入力欄を追加。先頭0、Enterで指定位置へ移動して一時停止します。
- 通常のH.264 MP4（30fps）、Hap MOV（30fps）、29.97fpsのMP4、前版で対応したMP4名のMPEG-TS素材（60fps）の4種類を、実際のアプリとGPU描画経路で確認しました。
- フレーム120への移動、移動後の一時停止維持、フレーム0への復帰、文字列・範囲外番号の拒否が通過しました。入力送信処理をアプリ内テストから呼び出して確認しています。
- 最終バイナリーでの初回統合テストはframe-input-rejectedで終了しました。原因は特定していません。同じバイナリーで再実行し、4種類すべて通過しました。初回記録は開発用のローカル検証記録に保存しています（素材名を含む実行ログはこのリポジトリには収録していません）。
- 下部バーと上部バーの高さが同じであること、幅780pxのウィンドウでも全操作部品が収まることを確認しました。数値は100%表示時です。
- FrameNumberラベルの幅を拡張し、文字の計測結果が表示幅以内であることを確認しました。実画面でも末尾の「r」まで見えることを確認しました。
- 上下操作バーの不透明度0.60、動画領域の背景色が黒であることを確認。実画面で黒い余白と細いバーを確認しました。
- 起動したテストプロセスの終了後、動画の解放完了とGPUエンジン数0を確認しました。

## 回帰確認

- Release / self-contained / ReadyToRunビルド：警告・エラーなし。
- --verify：96項目合格。
- --self-test：MP4、MOV、AVI、Hapなど12種類の合成素材を用いた55項目合格。
- レイアウト、TS形式判定、フレーム番号計算：979,198アサーション合格。フレーム計算は整数・小数フレームレート、範囲外、負数、小数入力、無効なフレームレート等を含みます。
- 自動テストはユーザー設定を読み書きしない設定で実施。素材動画は配布物に含めません。

## 制限

フレーム番号はファイルが報告するフレームレートと時間から算出しています。固定フレームレート素材向けで、可変フレームレートや不正確なメタデータを持つ素材の厳密な通算番号は保証しません。末尾の入力可能範囲も再生時間から推定します。

今回の実機確認は上記NVIDIA GPUと表示倍率100%で行いました。AMD/Intel GPUや他の表示倍率での追加実機確認、インストーラーの実行による更新確認は行っていません。

Sony X-OCN、Windowsの関連付け表示、配布ライセンス整理については変更していません。既知の事項はREADMEおよびTHIRD-PARTYを参照してください。
